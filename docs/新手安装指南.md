## 第 0 步：先搞懂两件事

**第一件：两种方式只是「拿文件夹」的方法不同。**

```
方式一 Git 克隆  ┐
                 ├──► 都得到同一个文件夹 ──► 启动步骤完全相同
方式二 下载 ZIP  ┘
```

所以别纠结选哪个，先看下面这段再决定：

| | 方式一：Git 克隆 | 方式二：下载 ZIP |
|---|---|---|
| 需要装 Git 吗 | 需要（你的 Mac 自带） | 不需要 |
| 更新到最新版 | 一条命令 `git pull` | 得重新下载一遍 |
| 适合谁 | 想长期用、想跟进更新 | 只想先看看、下完就跑 |

**第二件：命令要「在正确的文件夹里」执行。**

这是新手最容易踩的坑。终端就像一个「文件浏览器」，你让它执行命令时，它是在**你当前所在的文件夹**里干活。所以每一步我都会先让你确认「现在站在哪」。

## 名词速查

| 词 | 说人话 |
|---|---|
| **终端 / Terminal** | Mac 自带的一个黑色（或白色）窗口，在里面打字下命令 |
| **命令** | 在终端里敲的一行字，按回车执行 |
| **`cd`** | "change directory"，切换到某个文件夹 |
| **`ls`** | "list"，列出当前文件夹里有什么 |
| **`pwd`** | "print working directory"，我**现在**在哪个文件夹 |
| **粘贴** | 终端里粘贴是 `Command + V`（和平时一样） |

**怎么打开终端？**
按 `Command + 空格` → 输入 `终端` 或 `Terminal` → 回车。

## 先检查：你的电脑装齐了没有

打开终端，**逐行**复制粘贴下面 4 条命令（每粘贴一条按一次回车）：

```bash
git --version
```

```bash
node -v
```

```bash
npm -v
```

```bash
python3 -V
```

**期望看到类似这样的输出**（版本号不用完全一样）：

```
git version 2.50.1 (Apple Git-155)
v24.12.0
10.9.7
Python 3.12.4
```

- **四条都有版本号** → 完美，直接跳到[方式一](#方式一git-克隆推荐)或[方式二](#方式二下载-zip)
- **`node` 或 `npm` 报 `command not found`** → 去 <https://nodejs.org> 下载 **LTS** 版 `.pkg` 安装包，双击安装，装完**重开终端**再检查
- **`git` 报 `command not found`** → 在终端输入 `git --version`，macOS 会弹窗提示安装「命令行开发者工具」，点**安装**，等它装完（约 5 分钟）
- **`python3` 报错** → 去 <https://www.python.org/downloads/> 下载安装，装完重开终端

> 你可以随时回来重跑这 4 条命令，不会有任何副作用。

## 方式一：Git 克隆（推荐）

### 第 1 步：打开终端

`Command + 空格` → 输入 `终端` → 回车。

### 第 2 步：决定把项目放到哪，并「走过去」

推荐放桌面，命令如下：

```bash
cd ~/Desktop
```

> `~/Desktop` 就是你的桌面。想放别处也行，比如 `cd ~/Documents` 是文稿文件夹。

**确认到位：**

```bash
pwd
```

应该看到 `/Users/你的用户名/Desktop`。

### 第 3 步：把项目下载下来

```bash
git clone https://github.com/Peterolll/zscore-supplier-risk.git
```

回车后你会看到进度文字，几十秒内完成。桌面上会多出一个名为 **`zscore-supplier-risk`** 的文件夹。

> 这是公开仓库，**不需要**登录 GitHub 账号，也不会问你要密码。

### 第 4 步：进入这个文件夹

```bash
cd zscore-supplier-risk
```

**确认到位：**

```bash
pwd
```

应该看到 `/Users/你的用户名/Desktop/zscore-supplier-risk`。

✅ 方式一到此结束。接着看[共同步骤](#共同步骤启动系统两种方式都一样)。

## 方式二：下载 ZIP

### 第 1 步：打开仓库网页

浏览器访问：<https://github.com/Peterolll/zscore-supplier-risk>

### 第 2 步：找到那个绿色的 `Code` 按钮

它在文件列表的**右上方**，是一个绿色按钮，写着 `Code`（旁边有个小三角）。

### 第 3 步：点 `Code` → 点 `Download ZIP`

会弹出一个小菜单，最底下是 **`Download ZIP`**，点它。

浏览器会把 `zscore-supplier-risk-main.zip` 下载到你的**下载**文件夹。

### 第 4 步：解压

打开「访达」→ 左侧「下载」→ 双击那个 `.zip` 文件。

解压后得到文件夹 **`zscore-supplier-risk-main`**（注意末尾有 `-main`）。

### 第 5 步：把它拖到桌面（建议）

从「下载」文件夹把 `zscore-supplier-risk-main` 拖到桌面，这样下一步的路径好写。

### 第 6 步：在终端里进入这个文件夹

```bash
cd ~/Desktop/zscore-supplier-risk-main
```

**确认到位：**

```bash
pwd
```

应该看到 `/Users/你的用户名/Desktop/zscore-supplier-risk-main`。

> ⚠️ **注意文件夹名字不一样**：ZIP 解压出来是 `zscore-supplier-risk-main`（带 `-main`），Git 克隆出来是 `zscore-supplier-risk`（不带）。别搞混，否则 `cd` 会报 `No such file or directory`。

✅ 方式二到此结束。接着看下面的共同步骤。

## 共同步骤：启动系统（两种方式都一样）

> 下面的步骤**只需要做一次**（第一次装依赖）。以后启动见下一节。
>
> 前提：你已经在项目文件夹里（`pwd` 显示的路径末尾是 `zscore-supplier-risk` 或 `zscore-supplier-risk-main`）。

### 第 1 步：装 Python 环境（约 1–2 分钟）

```bash
python3 -m venv .venv
```

> 这条命令在项目里创建一个「独立的 Python 小房间」，不会污染你电脑上其他的 Python。跑完没有提示就是成功了。

```bash
./.venv/bin/pip install -r requirements.txt
```

> 这条会下载并安装解析财报需要的 Python 库。屏幕上会滚动很多行文字，**这是正常的**，等它停下来、回到可以输入的状态就好了。

**装完做一次自检**（强烈建议，能提前发现问题）：

```bash
./.venv/bin/python -c "import pdfplumber, pypdf, pptx, pydantic, openpyxl; print('依赖齐全')"
```

看到 `依赖齐全` 就说明这一步成功了。如果报 `ModuleNotFoundError`，把上面那条 `pip install` 再跑一遍。

> ⚠️ **这一步不要跳过。** 仓库里不放 `.venv` 文件夹（体积大且和操作系统绑定），
> 所以每个人都要自己装一次。跳过的话，上传财报时会提示引擎启动失败。
> 而且这个「小房间」是项目专属的，装了不会影响你电脑上其他的 Python 程序。
>
> 💡 你**不需要**额外安装 poppler / Homebrew 之类的工具。PDF 渲染与文本提取
> 已全部改用 Python 库（`pypdfium2` + `pdfplumber`），`requirements.txt` 一次装齐。

### 第 2 步：装网页环境（约 1–3 分钟）

```bash
cd zscore-web
```

```bash
npm install
```

> 会滚动大量内容，中间可能出现黄色的 `warning` 字样 —— **可以忽略**。
> 成功的标志是最后出现类似 `added 400 packages in 30s` 的提示。

### 第 3 步：回到项目根目录并启动

```bash
cd ..
```

```bash
bash start-zscore.sh
```

**成功的标志**，屏幕上出现：

```
启动成功 → http://localhost:3000
```

### 第 4 步：打开浏览器使用

在浏览器（Safari / Chrome 都行）地址栏输入：

```
http://localhost:3000
```

就能看到系统界面了。

### 第 5 步：开始用

1. 首页点击**上传财报并分析**
2. 选择供应商的财报文件（PDF / 扫描件 / PPTX 都行）
3. 填写供应商名称、行业、期间、会计准则、币种
4. 点分析 → 等几秒 → 看到 Z 值仪表盘和风险分区

## 以后每次怎么用 / 怎么关

### 启动（只需两步）

```bash
cd ~/Desktop/zscore-supplier-risk
```

```bash
bash start-zscore.sh
```

> 如果你用的是方式二，第二行对应的文件夹名是 `zscore-supplier-risk-main`。

然后浏览器打开 <http://localhost:3000>。

### 更新到最新版（仅方式一支持）

```bash
cd ~/Desktop/zscore-supplier-risk
git pull
```

拉完更新后，如果依赖有变化，重跑一次：

```bash
cd zscore-web && npm install && cd ..
```

### 关闭服务

系统是**后台运行**的，关掉终端窗口它也会继续跑（这样你才能一直用）。想彻底关掉：

```bash
lsof -ti :3000 | xargs kill
```

> 不想关也没关系，重启电脑会自动停。

### 如果提示「服务已在运行」

说明之前启动的还在跑，直接打开浏览器访问 <http://localhost:3000> 即可，不用重复启动。

## 常见问题排查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `cd: No such file or directory` | 文件夹名写错 / 不在那个位置 | 先 `ls` 看看当前有什么；确认方式一是不带 `-main`、方式二带 `-main` |
| `git: command not found` | Git 没装 | 输入 `git --version` 触发 macOS 弹窗安装 |
| `npm: command not found` | Node 没装 | 去 <https://nodejs.org> 装 LTS 版 `.pkg`，装完**重开终端** |
| `python3: command not found` | Python 没装 | 去 <https://www.python.org/downloads/> 下载安装 |
| `permission denied: start-zscore.sh` | 脚本没有执行权限 | 改用 `bash start-zscore.sh`（前面加 `bash` 即可绕过） |
| `ModuleNotFoundError: No module named 'pdfplumber'` | Python 依赖没装成功 | 回到项目根目录，重跑 `./.venv/bin/pip install -r requirements.txt` |
| `Could not find a version that satisfies the requirement ... (from versions: none)` | **不是包缺失**，是 pip 索引请求超时（默认只等 15 秒） | 换镜像并加长超时：`./.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple --timeout 120 -r requirements.txt` |
| 上传财报后提示**引擎启动失败 / SPAWN_ERROR** | 同上，Python 环境不完整 | 跑[第 1 步的自检命令](#第-1-步装-python-环境约-12-分钟)；确认 `pip install` 是在**项目根目录**执行的 |
| 只有一个 PDF 能分析，多个 PDF 一起传就报错 | 缺 `pypdf`（多文件合并用） | 重跑 `./.venv/bin/pip install -r requirements.txt` |
| 浏览器打不开 `localhost:3000` | 服务没起来 / 端口冲突 | 看终端最后几行提示；或先 `lsof -ti :3000 \| xargs kill` 再重新启动 |
| 页面上传财报后提示「待处理」 | 这是**扫描件**，需要额外的 OCR 密钥 | 电子文本 PDF 不受影响；扫描件需配置 `GLM_API_KEY` |
| 终端里粘贴不进去 | 快捷键不对 | 用 `Command + V` |
| 想中途取消正在跑的命令 | —— | 按 `Control + C` |

## Windows 用户说明

本指南的命令基于 macOS。**Windows 用户请看专门版本** —— 命令、Python 环境路径、
启动脚本全都不同：

👉 **[`新手安装指南-Windows.md`](./新手安装指南-Windows.md)**

两版命令对照速查：

| 用途 | macOS | Windows (PowerShell) |
|---|---|---|
| 建 Python 虚拟环境 | `python3 -m venv .venv` | `python -m venv .venv` |
| 调用 venv 里的 Python | `./.venv/bin/python` | `.\.venv\Scripts\python.exe` |
| 启动系统 | `bash start-zscore.sh` | `powershell -ExecutionPolicy Bypass -File .\start-zscore.ps1` |
| 关闭服务 | `lsof -ti :3000 \| xargs kill` | `Stop-Process -Name node -Force` |

## 一页速查卡

```bash
# ── 首次安装（只做一次）──
cd ~/Desktop                                              # 走到桌面
git clone https://github.com/Peterolll/zscore-supplier-risk.git
cd zscore-supplier-risk                                   # 进入项目
python3 -m venv .venv                                     # 建 Python 环境
./.venv/bin/pip install -r requirements.txt               # 装 Python 依赖
cd zscore-web && npm install && cd ..                     # 装网页依赖

# ── 每次启动 ──
cd ~/Desktop/zscore-supplier-risk
bash start-zscore.sh                                      # 看到「启动成功」即可
# 浏览器打开 http://localhost:3000

# ── 关闭 ──
lsof -ti :3000 | xargs kill
```
