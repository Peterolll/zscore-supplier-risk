关键设计取舍

取舍点选择理由
Sanitize 触发条件同页存在 ≥100K 数值时，纯整数 1-999 才视为序号避免小样本（如 1-999 区间本身就是真实金额）被误杀
L2 覆盖率门槛≥25% 判 conf=0.85，<25% 判 conf=0.7小微企业报表常仅 5-7 个子项（5/12≈42%）也能算
L3 推算仅在直接/子项均失败时启用，且 conf=0.7确保 UI 能标"推算待确认"，避免隐藏错误
字典自审gap 写入 DB 而非直接改字典避免 OCR 偶发噪声污染生产字典
闸门不阻断failed 仅标红 + 备注，仍计算 Z用户可见全貌，比"硬失败"更可调试
人工手填override 持久化 + 自动重算让领域知识（审计、调整）可沉淀
